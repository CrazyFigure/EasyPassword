## EasyPassword 双端软件开发（深夜）

基于 Ardot 设计稿开发 EasyPassword Flutter 应用（Android + Windows）。

### 技术栈与架构
- Flutter 3.44.8（Dart 3.12.2），Provider 状态管理
- SQLite（sqflite + sqflite_common_ffi），AES-256-GCM 字段加密（cryptography），PBKDF2 密钥派生
- WebDAV 增量同步（加密快照，先落本地再推送）
- GitHub Actions：tag 触发构建 APK（ubuntu）+ EXE（windows/NSIS）

### 关键决策
- 密码区（type=password）与 API Key 区（type=apikey）共用条目表物理分离
- 三级结构：password_items → accounts → api_keys（仅 apikey 区用第三级）
- 应用锁未开启时用 device_key 加密；开启后由密码派生主密钥
- path_provider_android 降级 2.2.17：2.3.x 引入 jni 插件，在无开发者模式的
  Windows 环境无法创建符号链接导致构建失败

### 环境限制（重要）
- 本机无 Windows 开发者模式 → flutter build windows 本地失败（符号链接权限）
- 本机无 Android SDK → APK 本地构建不可用
- 双端构建产物依赖 GitHub Actions CI
